# Environmental Monitoring

Android app for monitoring environmental data from IoT sensors (temperature, humidity, air quality, etc.).

## Features
- Real-time sensor data display
- Historical data charts
- Multiple sensor support
- Alert thresholds configuration

## Requirements
- Android Studio
- Android SDK 21+
- Compatible IoT sensors/network

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/environmental_monitoring.git
```
Open in Android Studio → Build → Run
